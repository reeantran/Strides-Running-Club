# Strides Running Club Website
Informative + easy-to-access site for prospective members of Strides Running Club! Includes information on the club, who leads the club, what we do, and how people can get involved.

## Setup

```bash
npm install
npm run dev        # localhost:3000
npm run build      # production build (same as Vercel does)
```

## Homepage
- Title + Club Photo
- Basic Q&A

## Cards Page
Includes rarities: Common, Uncommon, Rare, Epic, Legendary, Golden Card
Each rarity has its own page

## Officers Page
Includes list of officers for the term + a favorite route

## Schedule Page
Includes weekly schedule of officers and time of starting for each run
