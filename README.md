# Strides Running Club Website
A functional and responsive website for the Strides Running Club, including information about the club, its officers, events, scheduling, and its unique route cards
(website link + screenshot)
## How it's made
__Tech Used:__ HTML, Cascading Style Sheets (CSS), and Javascript  
  
This is my first front-end development project using these languages. I had learned these on my own through a couple of YouTube videos, and whenever
I hit a roadblock, a quick Google search was all I needed to keep progressing.

## Lessons Learned
For my first project, I definitely learned a lot. I gained basic and practical knowledge of each of the languages I had used in this project. I keep reminding myself that it's okay to find help by any means possible if it means I can keep moving forward in a project. 
I'm not always going to know everything that I need to do, and it never hurts to ask for help to help expand my knowledge of coding. Working as a group taught me that input from a variety of sources helps to gain perspectives about what we might and might not want in a project.
